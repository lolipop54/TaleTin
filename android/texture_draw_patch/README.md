# 原书阅读的离屏绘制补丁

上游源码来自 Flutter 引擎 a804b261645ef8c13eb3d5c44a5c2fb0340c5539 的
`engine/src/flutter/shell/platform/android/io/flutter/plugin/platform/PlatformViewWrapper.java`。
原 BSD 许可在同目录 LICENSE。当前 SDK 为 Flutter 3.47.2。

保留上游绘制、触摸、焦点和资源接口。只增加逐视图选择的内容失效调度：
原书滚动使用模式 3，把同一轮内容通知合并到原生帧回调，直接更新原尺寸硬件纹理，
不让每次正文滚动都额外提交主窗口。模式 0 保持上游；模式 1 仅供诊断。
原书分页使用模式 2，只将内容失效合并到单次帧回调，不在截图翻页期间连续补画网页。
同包快速翻页对照中，模式 2 的慢间隔少于原管线；沿用滚动的连续补画反而更多，未采用。
真实原生滚动回调将绘制窗口延续250ms，手指按下也开始一次；停稳后不再持续绘制。
这样不仅Flutter有帧，网页纹理本身也能持续更新，避免复用旧纹理造成顿挫。
布局、尺寸、窗口绘制仍经过原窗口；停止、销毁、离开视图树时取消待执行回调。
绘制本身再次要求刷新时放在下一帧，避免消息队列不停重画。

`OriginalScrollDraw.enable` 在首个完整页面确认后开启原书滚动；
`enablePaged` 由物理分页宿主在首次 `presented` 完成后调用一次，只切换该视图。
iframe、其它平台视图和旧 Android 不因此更换调度；后续目标页仍执行完整 `presented`。
显式跳转的 `PageCapture.presented` 仍主动使包装视图失效，经过完整窗口绘制再确认。
硬件画布、透明清除、SurfaceProducer 和同步围栏保持上游实现，像素尺寸不变。

构建时编译本项目的替换类，通过 AGP ScopedArtifact.CLASSES 合并字节码；
只排除依赖 JAR 中的上游同名类及其内部类，不改 SDK 或依赖缓存。
同时核对引擎版本和上游类 SHA-256。升级 Flutter 必须重新比较上游实现、更新补丁并真机验证，
不能直接删掉检查以让升级通过。关闭实际行为需取消相应入口的 enable / enablePaged 调用；
完全移除时同时移除该通道、新增方法调用及 Gradle apply。

性能和未通过条件见 docs/原书滚动离屏调度与跟手优化261023.md
与 docs/原书分页按需绘制与剩余慢帧261023.md。
